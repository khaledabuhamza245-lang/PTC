# PTC Hub — Frontend

الواجهة الثابتة لموقع "زاد الطالب" (PTC Hub) — HTML/CSS/JS عادي بدون أي إطار عمل (framework)، متصلة بباك إند Laravel الموجود بمجلد `../backend`.

## التشغيل محليًا

1. تأكد إن `api-config.js` مضبوط على رابط الباك إند الصحيح (محلي أو الإنتاج).
2. شغّل الملفات بأي سيرفر ثابت (Live Server بـ VS Code مثلًا) — لا تفتحها مباشرة بـ `file://`.

## النشر (Deployment)

النشر الحالي يدوي عبر File Manager بلوحة cPanel — ما في نشر تلقائي مربوط بجيت هاب حاليًا. أي تعديل تحفظه هنا لازم يُرفع يدويًا لمجلد `public_html` على الاستضافة بعد كل تعديل.
