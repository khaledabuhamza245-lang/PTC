خطوة إعداد "تذكيرات المحاضرات" التلقائية — تحتاج Cron Job واحد بلوحة
cPanel (خطوة يدوية لمرة واحدة، بلا حاجة لصلاحية SSH).

ليش لازم Cron يدوي؟
البوت ما إله وصول SSH ولا artisan تفاعلي بهاي الاستضافة، فما فيه queue
worker حقيقي يشتغل تلقائيًا بالخلفية. أمر "telegram:send-lecture-reminders"
لازم يتكرر تنفيذه كل ٥ دقائق من مكان خارجي — وأنسب مكان هو "Cron Jobs"
بلوحة cPanel نفسها.

خطوات الإعداد:

1) ادخل لوحة cPanel → دوّر على "Cron Jobs" (وظائف Cron).

2) بقسم "Add New Cron Job":
   - Common Settings: اختر "Every 5 Minutes" (أو حدد يدويًا: Minute = */5،
     باقي الحقول *).

3) بخانة "Command" اكتب (بدّل المسار حسب مكان مجلد الباك إند الفعلي على
   السيرفر — غالبًا نفس مجلد "ptc-hub-backend" يلي ينشر فيه GitHub
   Actions تلقائيًا، جنب public_html):

   /usr/local/bin/php /home/USERNAME/ptc-hub-backend/artisan telegram:send-lecture-reminders >/dev/null 2>&1

   ملاحظات على الأمر:
   - "USERNAME" بدّلها باسم مستخدم الاستضافة الفعلي (نفس الي تشوفه
     بمسارات ملفاتك بـFile Manager، مثلًا /home/ptchub123/...).
   - "/usr/local/bin/php" هو مسار PHP الشائع بمعظم استضافات cPanel — لو
     ما اشتغل، دوّر على "Setup PHP App" أو "Select PHP Version" بلوحة
     cPanel وشوف مسار PHP CLI المكتوب هناك (أحيانًا بيكون بصيغة
     /usr/local/bin/php8.3 أو مشابه لرقم إصدار PHP المستخدم بالمشروع).
   - لازم يكون إصدار PHP هون نفسه إصدار المشروع (PHP 8.3) وإلا ممكن
     يفشل الأمر بصمت.

4) احفظ (Add New Cron Job). أول تنفيذ رح يصير خلال ٥ دقائق كحد أقصى.

5) للتحقق إنه شغّال: انتظر لحد ما يقرب وقت محاضرة حقيقية بجدولك (بين
   ١٠ و١٥ دقيقة قبل بدايتها بالضبط)، وشوف إذا وصلتك رسالة تذكير بالبوت.
   بديل أسرع للتجربة الفورية: عدّل مؤقتًا وقت بداية محاضرة موجودة بجدولك
   (من صفحة "جدول المحاضرات" بالموقع) ليصير بعد ١٢-١٣ دقيقة من الوقت
   الحالي، وانتظر تشغيلة الـCron التالية.

لا تحتاج تكرر هذي الخطوة أبدًا بعد الإعداد الأول — الأمر رح يستمر
يشتغل تلقائيًا كل ٥ دقائق للأبد، ونظام الحماية الداخلي (Cache dedupe)
بيضمن ما يتكرر نفس التذكير مرتين لنفس المحاضرة بنفس اليوم حتى لو
تشغيل الـCron تأخر أو تكرر بالغلط.
