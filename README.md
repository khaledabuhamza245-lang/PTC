# PTC Hub — زاد الطالب

منصة طلابية لقسم هندسة أنظمة الحاسوب بكلية فلسطين التقنية، مبنية من جزأين بنفس الريبو:

- **`frontend/`** — الواجهة الثابتة (HTML/CSS/JS عادي، بدون إطار عمل)، وهي نفس الملفات المرفوعة على `public_html` بالاستضافة.
- **`backend/`** — باك إند Laravel (PHP)، مسؤول عن الـ API وقاعدة البيانات وكل منطق التسجيل والمواد والخطط الدراسية.

## كيف يشتغل الموقع فعليًا

الموقع مباشر على استضافة cPanel (بدون SSH ولا صلاحيات artisan)، والنشر حاليًا **يدوي بالكامل**: أي تعديل يُختبر ويُتأكد منه هنا (أو محليًا)، وبعدين يُرفع يدويًا عبر File Manager لمجلدي `public_html` (للواجهة) و`ptc-hub-backend` (للباك إند) على السيرفر.

**هذا الريبو مصدر الكود والتاريخ الكامل للتعديلات — مو استضافة الموقع نفسه.** رفع تعديل هون على جيت هاب لا يغيّر شيء على الموقع المباشر تلقائيًا؛ خطوة الرفع للسيرفر تبقى منفصلة دائمًا بعد كل تعديل تأكدنا منه.

## ملاحظة أمنية مهمة

مجلد `backend/` **لا يحتوي على `vendor/` ولا على ملف `.env` الحقيقي** عن قصد — هذول فيهم مكتبات كبيرة يُعاد توليدها تلقائيًا، وأسرار حقيقية (كلمة سر قاعدة البيانات، مفاتيح خدمات خارجية) ما يصح تكون بأي ريبو جيت هاب حتى لو خاص. بدالهم موجود `.env.example` كقالب فاضي من الأسرار.
